# CMPMIV-NA-UNIVERSIDADE
CMPMIV na Universidade é uma plataforma desenvolvida para acompanhar a trajetória dos alunos do Ensino Médio rumo ao ensino superior. O aplicativo permite registrar notas, acompanhar médias, consultar notas de corte do PSS, SIS, UEA e ENEM, simular possibilidades de aprovação e monitorar o desempenho de cada estudante.
