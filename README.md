# CMPMIV na Universidade

Aplicativo Android para acompanhamento de alunos e comparação de notas com referências de corte de ENEM, PSS, SIS e UEA.

## Como gerar o APK
1. Abra esta pasta no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Use **Build > Build APK(s)**.
4. O APK de debug será gerado em `app/build/outputs/apk/debug/app-debug.apk`.

## Observação
O app usa armazenamento local no dispositivo. As notas de corte precisam ser cadastradas/conferidas pelo responsável e não representam garantia de aprovação.
